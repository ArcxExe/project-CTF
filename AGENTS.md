# Правила репозитория

## Git-коммиты после выполнения задачи
- После завершения любой задачи с изменениями в репозитории и успешного прогона проверок/тестов обязательно создавай локальный `git commit`.
- Включай в коммит только файлы, относящиеся к выполненной задаче (проверяй `git status` и `git diff` перед `git add`).
- Форматируй сообщение коммита в стиле Conventional Commits (например, `fix(backend): ... (#31)` или `feat(scope): ...`).
- Не выполняй `git push` без явного запроса пользователя.
- Если проверки/тесты не пройдены или задача не завершена, не делай коммит.
